# ArchBang Classic

Old-school ArchBang: Openbox on X11, BIOS-only live ISO. No installer.

- Openbox + tint2 + lxterminal
- rofi launcher, feh wallpaper, dunst notifications
- nm-applet, volumeicon, slock
- syslinux boot only (no UEFI)
- live user, wheel group, passwordless sudo, startx on tty1

## Building

See `profiledef.sh` and `airootfs/root/customize_airootfs.sh`.
